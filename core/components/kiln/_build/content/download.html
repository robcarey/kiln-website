After you install

  1. Open Kiln. The setup check runs and walks you through anything that needs a fix.
  2. Kiln asks for administrator permission when it installs its local certificate authority and updates the hosts file with your site names.
  3. Add your first site — or install WordPress, MODX, Joomla or Grav with Pro — and open it over HTTPS.

Verify your download

Each installer is signed. You can also compare its SHA-256 checksum with the value above:

# Windows (PowerShell)
Get-FileHash .\Kiln-[[++kiln.current_version]]-setup.exe -Algorithm SHA256

# macOS
shasum -a 256 ~/Downloads/Kiln-[[++kiln.current_version]]-arm64.dmg
