Respect for your machine

Your computer stays yours.

Kiln is self-contained by design. It brings its own runtimes, keeps them in one place, and takes everything with it when you say goodbye.

Everything in one folder

Runtimes, configs, certificates and logs live in Kiln’s data folder — not scattered across your system.

Only what you ask for

Pick the PHP versions and services you want. Kiln fetches those, and nothing else.

Signed installers

The Windows installer is code-signed, and the Mac builds are signed and notarized by Apple.

Test mail stays local

The mail catcher only listens on your own machine, so test emails can’t reach real people.

Secrets kept secret

Remote host passwords are encrypted at rest and SSH host keys are pinned on first connect.

A clean goodbye

Uninstall from Settings removes Kiln’s certificate authority, hosts entries and helpers — and the data folder too, if you want.
